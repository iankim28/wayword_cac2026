# Wayword

Written by Ian Kim.

![Wayword cover: a voice waveform leading to a map pin, with the words Voice destination finder](Wayword2026.jpg)

Wayword is a voice destination finder for drivers near Andover, Massachusetts. Say a place name. It listens, matches Massachusetts names that are easy to mishear, and shows the place. From there you can open the trip in Apple Maps or Google Maps.

The app has three screens: Talk, Result, and History. A place you correct by typing is remembered the next time.

## Run

```
python3 server/server.py
```

Open http://127.0.0.1:5173
